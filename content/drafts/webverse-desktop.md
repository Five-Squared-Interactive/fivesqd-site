# WebVerse for the desktop (draft)

*Goes live when a desktop build is downloadable.*

The client is a web page, and most of the time that is all you need. A
desktop version of the same client exists for the cases a browser tab
cannot cover: worlds on a local network with no internet, kiosks and
installations, opening a world from a folder on disk, and a window that
stays full screen. It opens the same documents and shows the same worlds;
nothing about a world changes for it.

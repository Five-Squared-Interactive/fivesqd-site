# The published world's page (draft)

The words on the page a published link opens, around the world itself.
Lives in the publish service (v4-monorepo, `services/worldhub-publish`),
not on this site. Here so the whole story reads in one place.

## Beside the world, for every visitor

**What is this?** *(a small link; opens a panel)*

This is a world: a web page someone exported from Blender. Walk around
with the mouse and keys, or drag and use the stick on a phone. If someone
else is here, you will see them.

- **Open the document** — the file behind this world, as text.
- **Download this world** — the folder. Put it on any web host and the
  link works there too.
- **Make your own** — install the add-on, press Save as My World.

## Beside the world, for its owner

**Edit the document** *(owner only; a text box with the VEML, a Save
button)*

Change the title, the starting point, the sky; add a link to another
world. Save, and the page reloads with the change. What you change here is
in the file; publish again from Blender and the scene's export replaces it,
so keep changes you want to last in Blender too.

## The first-visit hint (already in the client; one line added)

Click to look around · Esc gives the mouse back
W A S D to move · Shift to run · Space to jump
F to fly, where the world allows it — Space up, Shift down
H shows this again

# MyWorlds (draft)

*Goes live when MyWorlds runs on the new client.*

## Assemble a world in the browser

Not everyone has a Blender scene. MyWorlds is where you put a world
together from parts, in the browser, in the same client that visitors
use: place things, move them, set where people start, name the world, and
it is live at a link while you work.

## It is still a document

What you assemble is the same VEML document a Blender export produces. You
can open it as text, download it, put it on your own host, link it to
other worlds. MyWorlds is an editor for the page, not a different kind of
world.

## Together, as you build

Because a world's changes are kept by a runtime (WorldOS), two people can
build the same world at once and see each other's changes, and visitors
arriving later see the world as it was left.
